# AVRIL // SYSTEM PROFILE

I'm an informatics student, frontend engineer, and security researcher. Or whatever the hell title people want to slap on it.

This repository holds the raw source code for my personal portfolio. I got violently sick of staring at those boring, cookie-cutter scrolling websites with zero personality, so I burned it all down. I stripped away the traditional web slop and rebuilt this thing as a pseudo-SPA mimicking a Cyberpunk terminal menu. It's minimal, aggressive, and heavily focused on frontend physics. No bloated frameworks, no React wrappers, just raw DOM manipulation.

## ARCHITECTURE & LAYOUT
- **Cyberpunk UI**: Deep radial red/black gradients, CRT scanlines, static SVG noise, and custom vignettes. Typography relies purely on local Airstrike and Nasalization fonts because standard system fonts look like corporate trash.
- **Fluid Mechanics**: Instead of standard CSS hover states and jumpy layout shifts that make me want to gouge my eyes out, everything relies on brutal GSAP transforms. The main menu physically shrinks and glides to the side to reveal content tabs. Zero layout thrashing.
- **Terminal Lists**: The content inside the tabs utilizes flattened grids. No clunky background boxes, just transparent lists, clean separator lines, and subtle cyan glows. Pure, raw data.

## SYSTEM CAPABILITIES
- **Frontend Eng**: Pushing GSAP to its absolute limits, manipulating the DOM so pixels move exactly how I want them to.
- **Linux SysAdmin**: Hopelessly deep in the Linux sysadmin rabbit hole. Ricing my Arch setup, patching Hyprland configs, injecting custom Wayland widgets, and tinkering with kernel parameters until something inevitably crashes at 3 AM.
- **Security Research**: Messing around with custom pentesting workflows (hooking up Nuclei and Metasploit RPC just to see things break), and writing automation scripts so I don't have to deal with repetitive garbage.
- **Visual Assets**: Building high fidelity vector illustrations and splicing motion graphics because standard templates are for the weak.

3. **[Graphic Design](graphicdesign.html) & [Motion Visuals](motionvisuals.html)**
   Designing high fidelity vector assets and rendering dynamic motion graphics with heavily modified easing curves. No cheap presets allowed. Every asset is built from scratch with absolute precision.
   
4. **[Street Photo](photography.html)**
   Wandering around concrete jungles capturing raw, unfiltered moments of urban decay and human exhaustion. Aggressively edgy cinematic color grading to match my chronically sleep-deprived state.

## TECH STACK
- **HTML/CSS**: Structural foundation. Zero UI frameworks. CSS grid and flexbox doing the heavy lifting.
- **Vanilla JS**: No bloated virtual DOMs here. Direct DOM manipulation only.
- **GSAP**: The absolute core of the UI physics. Because standard CSS animations are rigid, lifeless, and boring.
