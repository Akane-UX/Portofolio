Konsep Desain UI/UX

Aplikasi E-Management ini dirombak ulang secara total dari bentuk input daftar konvensional menjadi gaya Bento Grid yang sangat modern dan rapi. Layout asimetris mempermudah hierarki visual, memberikan pengguna pengalaman yang jauh lebih intuitif saat mengelola dana.

Validasi Real-time & Sliders

Salah satu pain point dari aplikasi pencatat keuangan adalah pengguna sering memasukkan angka yang melebihi saldo awal. Untuk mengatasi ini, saya mengganti kolom teks dengan fitur Slider Interaktif. Saat satu slider digeser, logika JavaScript (Vanilla) secara real-time memvalidasi dan membatasi alokasi agar tidak pernah melampaui sisa uang (Remaining Balance), memberikan feedback instan tanpa perlu menekan tombol Submit.

Arsitektur Frontend

Client-side Storage

Aplikasi beroperasi secara penuh di *browser* menggunakan LocalStorage API. Sangat cepat, tanpa loading server, dan menjaga privasi finansial pengguna secara total.

Tailwind Utility

Menggunakan TailwindCSS untuk menerapkan desain responsif dan *Bento Grid* dengan sangat efisien tanpa *bloatware* CSS yang berat.

Category Selection

Tahap pra-alokasi memungkinkan pengguna memilih *preset* kategori (misal: 50/30/20 Rule) atau meracik kategori kustom mereka sendiri.
