E-Management App

E-Management is a modern personal finance tracker built entirely on the client side. The goal was to transform a standard budgeting tool into a premium, interactive experience.

Bento Grid Redesign

Moving away from traditional lists, the dashboard utilizes a sleek Bento Grid layout to display financial summaries, alerts, and quick actions asynchronously.

Real-time Validation

Instead of simple text inputs, the app features dynamic sliders for budget allocation. The sliders are validated in real-time via Vanilla JS, preventing users from exceeding their 100% balance.

Local Storage Architecture

Designed for maximum privacy and speed, the entire state is persisted securely in the browser's LocalStorage, requiring zero backend dependencies.
