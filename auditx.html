FILE_READ // OVERVIEW

> WHAT_IS_AUDITX

A native Linux desktop app built with Quickshell QML and a Python backend. I basically took a bunch of messy, intimidating CLI security tools and slapped them into a slick, centralized GUI. Zero bloat, pure functionality.

> WHY_I_BUILT_IT

Let's be real, staring at raw Nmap or Metasploit terminal dumps can melt your brain if you're just starting out. I built this to break down that wall. Point, click, and run vuln scans or dir fuzzing without having to memorize a 50-character bash command.

SYSTEM_MODULES // LOGS

[01] VISUAL_VULN_SCAN

Hooked up Nuclei under the hood. Finds web vulnerabilities and formats the output so it's actually readable instead of a massive text wall.

[02] DIR_FUZZING

Integrated Gobuster. Just plug in your target and wordlist through the UI and let it rip.

[03] NETWORK_OSINT

Runs NetExec, Enum4Linux-NG, and Gitleaks. Perfect for sniffing around networks and catching leaked secrets.

[04] MSF_RPC_LINK

Talks directly to msfrpcd. You can generate payloads with Msfvenom and manage listeners straight from the dashboard.
