FILE_READ // OVERVIEW

> WHAT_IS_AUDITX

A native Linux desktop app glued together with Quickshell QML and Python. I got sick of staring at messy, unreadable CLI dumps from security tools, so I forced them into a slick, centralized GUI. Zero bloated web-tech slop, just pure functionality that actually works without eating half my RAM.

> WHY_I_BUILT_IT

Let's be real, parsing raw Nmap or Metasploit terminal dumps at 3 AM will literally melt your brain. I built this because I have zero patience for memorizing 50-character bash commands just to run a basic vuln scan. Just point, click, and let the tool do the heavy lifting while I drink my coffee in peace.

TERMINAL_EDITION // AUDITX_CLI

> CLI_STANDALONE_ORCHESTRATOR

An interactive terminal wrapper and security orchestrator built for rapid security auditing, OSINT reconnaissance, and network triage. Standalone Python architecture stripped of all heavy GUI dependencies, built to run blazing fast on any modern terminal emulator with zero overhead.

> WHY_THE_CLI_EDITION

GUIs are neat until you are SSH'd into a remote box or living inside a minimal Arch rice without a display server running. Remembering dozens of syntax variations across 18 different security tools at 3 AM is miserable. This CLI edition lets you pick tools from a clean ASCII HUD, plug in targets, and stream execution in real time.

[CLI_01] OSINT & RECON

SHERLOCK

Sherlock, theHarvester, Sublist3r, and Gitleaks. Fast automated tracking for leaked secrets, DNS records, and social handles without digging manually.

[CLI_02] NETWORK_TRIAGE

NMAP / RUSTSCAN

Built-in local IP resolution and subnet discovery alongside Nmap, RustScan, NetExec, and Enum4Linux-NG for rapid host sweeps and SMB auditing.

[CLI_03] WEB_APP_AUDIT

SQLMAP / NIKTO

Nuclei YAML template scanning, Gobuster directory fuzzing, SQLMap automated injections, Nikto web scanning, and WhatWeb fingerprinting.

[CLI_04] MSF_RPC_DIRECT

METASPLOIT

Direct communication with msfrpcd. Auxiliary module execution, dynamic Msfvenom payload generation, and handler listener management right from your shell.
