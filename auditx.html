Apa itu AuditX?

AuditX adalah aplikasi native desktop berbasis Linux (dibangun dengan Quickshell QML & Python Backend) yang berfungsi sebagai platform audit keamanan (security auditing). AuditX menyatukan berbagai command-line tools (CLI) keamanan siber yang rumit ke dalam satu antarmuka grafis (GUI) yang terpusat dan modern.

Mengapa Saya Membangun Ini?

Bagi orang awam atau pemula di bidang keamanan jaringan, melihat rentetan teks di terminal (seperti saat menggunakan Nmap atau Metasploit) bisa sangat mengintimidasi. Saya mengembangkan AuditX untuk mendobrak dinding batasan tersebut. Dengan memberikan antarmuka visual, proses scanning kerentanan, directory fuzzing, hingga penyusunan payload dapat dipahami dan dijalankan dengan beberapa kali klik saja tanpa harus menghafal perintah panjang.

Fitur Utama

Visual Vulnerability Scan

Mengintegrasikan Nuclei untuk menemukan celah keamanan web dengan tampilan hasil yang terstruktur, bukan sekadar teks acak.

Directory Fuzzing

Menggunakan Gobuster dengan GUI yang memudahkan pengguna awam memasukkan wordlist dengan sekali klik.

Network & OSINT

Mendukung NetExec, Enum4Linux-NG, serta Gitleaks (Secret Scanner) untuk audit jaringan dan mencari data sensitif yang bocor.

Metasploit RPC

Di-orkestrasikan dengan msfrpcd dan API, memungkinkan pengguna men-generate payload (Msfvenom) dan mengatur Listener melalui UI secara aman.
